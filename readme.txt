[b]Advanced Multilingual News[/b]
Version 1.0.12

[b]Compatibility[/b]
SMF 2.1.0 - 2.1.99

[b]Features[/b]
[list]
[li]Separate text for every installed SMF language.[/li]
[li]Per-news-item visibility for guests, regular members, normal member groups, and post-count based groups.[/li]
[li]Uses SMF's currently active runtime language, including browser-detected languages for guests.[/li]
[li]Falls back to the forum default language when a translation is empty.[/li]
[li]BBC remains supported.[/li]
[li]Per-language BBC preview beside every news text field.[/li]
[li]One-click selection or deselection of all groups per news item.[/li]
[li]Uses integration hooks only; no SMF core or theme source modifications.[/li]
[li]Existing SMF news is imported during installation.[/li]
[li]On uninstall, enabled entries in the forum default language are written back to SMF's standard news setting.[/li]
[/list]

[b]Administration[/b]
Admin Center -> News and Newsletters -> News

For every entry, fill the desired language fields and select all groups that may see the entry. An entry with no selected groups is visible to nobody.
